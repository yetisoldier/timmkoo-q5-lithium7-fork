# v1.0.0 — first official Q5 Gen 7 release

**Lithium 7 for Q5 Gen 7 (Q5 Mint)** is the first official release of this
community fork. It targets the Mint-style MT6582 Q5 with one front Home circle
and a 480×800 screen. It is not a TIMMKOO manufacturer release or a universal
Q5 firmware image.

## Included

- Android 7.1.2 with restored touch, Home, speaker and wired headphone support.
- Tap Home, double-tap Back, hold Recent Apps; visible navigation buttons with
  a Settings visibility switch.
- FM headphone playback with working volume buttons and pause/resume.
- Microphone recorder, USB MTP transfer and tested H.264 720p hardware playback.
- Gnome boot artwork/wallpaper, removal of the unused Lawnfeed prompt, and
  removal of browser/Open Camera/Xposed Installer apps from defaults.
- WebView 119 for app screens, including Audiobookshelf's server connection UI.
- Q5 Gen 7 v1.0.0 version identification in Settings and `/system/etc/q5-release.json`.

The hardware/kernel, Home policy, speaker and FM audio fixes are the same
configurations verified on the development unit. This release labels and
packages those fixes for a clean installation; it does not claim an Android
security update.

## Installation and validation

Use the [installation guide](https://github.com/yetisoldier/timmkoo-q5-lithium7-fork/blob/v1.0.0/docs/INSTALL.md). The release writes only boot,
system and logo. A clean install formats internal data and clears cache;
preloader, bootloader, recovery, partition tables, NVRAM and calibration are
not included or written. Existing compatible TWRP/ADB is the tested install route.

Exact firmware/member checksums and release validation are recorded in
`manifests/release-v1.0.0.json`. The release assets include the corresponding
patched kernel source and F-Droid Audio Recorder source.

## Known limits

Bluetooth paired audio/reconnect/buttons, low-battery charging and battery
life, unplugged deep sleep, FM speaker/Bluetooth output/full station scan,
other sensor behavior and third-party account playback remain unverified.
No fitted camera sensor was established; no camera app is supplied.

Audiobookshelf, Plexamp and Apple Music are optional and not bundled. Google
services are not bundled. Browser removal is not parental filtering.
Android 7.1.2/WebView 119 are legacy components; the inherited security patch
label is 2018-04-05, and the base remains userdebug. Inactive Xposed files
remain, although its installer is removed and no fixes depend on it.

This release replaces the development checkpoints, including the superseded
silent direct-route FM configuration. Do not mix their images with v1.0.0.
