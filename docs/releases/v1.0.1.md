# v1.0.1 — Wi-Fi recovery and music-player refinements

For the MT6582 Q5 Gen 7 / Q5 Mint only, with the same supported hardware and
partition layout as v1.0.0. This is a community release, not a vendor update.

- D43 kernel keeps a persistent locally administered Wi-Fi address when the
  device has no valid factory address, without changing NVRAM or calibration.
- Bounded startup recovery retries a stalled saved WPA-PSK association up to
  twice, then exits. Six rapid cycles retained one address and internet access;
  one genuinely stalled cycle recovered after the first retry.
- Wi-Fi-only framework and boot configuration removes SIM/call notices and
  stops unused cellular modem services while retaining Wi-Fi/Bluetooth drivers.
- Restores the intended ART heap/compilation defaults by removing stale overrides.
- Adds a normally hidden, restricted Plex sign-in window, successfully used
  with Saga. No general-purpose browser or app store is included.
- Adds a supported data-preserving recovery upgrade from official v1.0.0.

Existing touch, Home shortcuts, visible/toggleable navigation, speaker,
headphone, recorder, FM, storage and gnome artwork fixes are retained.
Optional streaming/audiobook clients and their private accounts are not bundled.
Apple Music motion settings and Plexamp Flat-background recommendations are
in the README; no quantified app speed increase is claimed.

Use [the installation guide](../INSTALL.md). Choose `--upgrade` only from a
supported official release; choose `--factory-reset` for Mint/other ROMs.
Only boot, system and logo are written. Never use Format All or Firmware
Upgrade in SP Flash Tool. Keep a backup before either installation method.

The release includes matching patched kernel source and recorder source.
Android 7.1.2/WebView 119 remain legacy components; no security-patch update
is claimed. Paired Bluetooth audio, full FM scan/speaker routing, battery life,
low-battery charging and unplugged deep sleep retain the v1.0.0 validation limits.
FM listening after disabling cellular services was deferred at the owner's
request. No fitted camera sensor has been established.


The inherited Settings Notification Drawer customization screen has a recorded
ClassCastException and remains an open issue. This is separate from playback.

Validated on the connected Q5 using the data-preserving upgrade: all three
images matched full readback hashes, package state/adopted keys were unchanged,
35 generated system files matched, Wi-Fi connected automatically with internet,
cellular helpers were absent, and Chronicle reopened its signed-in library.
Animations remained off. The hidden Plex handler resolved only supported sign-in
links; general HTTPS and launcher queries had no matching browser activity.
